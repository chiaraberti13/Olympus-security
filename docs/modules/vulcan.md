# Vulcan — Findings aggregation & pentest reporting

> **🇮🇹 Italiano** · [🇬🇧 English below](#-english)

## 🇮🇹 Italiano

### Cosa fa
Vulcan è il modulo Purple di Olympus che chiude il ciclo: **aggrega** gli output di tutti
gli altri moduli, li **deduplica**, li **ordina per rischio**, e produce il **report di
pentest** finale. È il punto in cui il design dell'intera piattaforma — un contratto dati
condiviso (`olympus.core`) attraversato da ogni modulo mantenendo lo stesso ID — ripaga
davvero: Vulcan non deve sapere nulla della logica specifica di Argus, Helios, Apollo o
Proteus, gli basta riconoscere `schema_name`.

- **Aggregazione generica** — `load_export()`/`aggregate()` camminano ricorsivamente
  qualunque struttura JSON cercando oggetti con `schema_name` riconosciuto
  (`olympus.asset`/`.finding`/`.alert`), indipendentemente dalla forma esatta del file
  (lista semplice per Argus, oggetto annidato per Helios/Artemis/Proteus). Deduplica per ID
  tra più file.
- **Risk scoring** — ordina i finding per rischio: CVSS quando presente (score calibrato
  0-10), severità come spareggio/fallback.
- **Report di pentest** — genera un report Markdown leggibile con riepilogo, finding
  ordinati per rischio, e alert con tecnica MITRE.
- **Export conforme al core** — `vulcan-report.json`, round-trip validato.

### Comandi
```bash
# Demo reale: aggrega l'output reale di argus/helios/artemis/apollo/proteus demo
olympus vulcan demo
```
*(Esegui prima gli altri demo se `examples/output/` non contiene ancora i loro file — il
demo Vulcan salta con un avviso le fonti mancanti, senza fallire.)*

### Output
Il demo produce `examples/output/vulcan-report.md` (leggibile da un umano) e
`examples/output/vulcan-report.json` (conforme a `olympus.core`, per un consumo
automatizzato a valle).

### Esempi
`examples/output/vulcan-report.md` e `examples/output/vulcan-report.json` sono l'output
reale del comando `demo`, generato aggregando i file reali prodotti dagli altri cinque
moduli.

### Etica
Nessun dato reale: aggrega esclusivamente gli output sintetici già prodotti dagli altri
moduli su "Olympus Demo Corp".

## 🇬🇧 English

### What it does
Vulcan is Olympus's Purple module closing the loop: it **aggregates** every other module's
output, **deduplicates** it, **ranks it by risk**, and produces the final **pentest
report**. This is where the platform's whole design — a shared data contract
(`olympus.core`) that every module writes to, keeping the same object ID — actually pays
off: Vulcan needs to know nothing about Argus's, Helios's, Apollo's or Proteus's specific
logic, it only needs to recognize `schema_name`.

- **Generic aggregation** — `load_export()`/`aggregate()` recursively walk any JSON
  structure looking for objects with a recognized `schema_name`
  (`olympus.asset`/`.finding`/`.alert`), regardless of the file's exact shape (a plain list
  for Argus, a nested object for Helios/Artemis/Proteus). Deduplicates by id across files.
- **Risk scoring** — ranks findings by risk: CVSS when present (a calibrated 0-10 score),
  severity as tiebreaker/fallback.
- **Pentest report** — generates a readable Markdown report with a summary, risk-ranked
  findings, and alerts with their MITRE technique.
- **Core-conforming export** — `vulcan-report.json`, round-trip validated.

### Commands
```bash
# Real demo: aggregates the actual output of argus/helios/artemis/apollo/proteus demo
olympus vulcan demo
```
*(Run the other demos first if `examples/output/` doesn't have their files yet — Vulcan's
demo skips missing sources with a warning, it doesn't fail.)*

### Output
The demo produces `examples/output/vulcan-report.md` (human-readable) and
`examples/output/vulcan-report.json` (conforming to `olympus.core`, for downstream
automated consumption).

### Examples
`examples/output/vulcan-report.md` and `examples/output/vulcan-report.json` are the
`demo` command's real output, generated by aggregating the real files the other five
modules produced.

### Ethics
No real data: it only ever aggregates the synthetic output already produced by other
modules against "Olympus Demo Corp".
